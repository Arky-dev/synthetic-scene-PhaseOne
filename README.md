# Synthetic Scene Creation Pipeline

This project is a C++/OpenGL synthetic scene generation software developed to evaluate photogrammetric calibration accuracy and repeatability for Phase One A/S. It aims to isolate optimization algorithms from physical environmental noise, such as thermal drift and sensor noise, by rendering high-resolution synthetic image sets with custom optical blur, lens distortion, and automated EXIF metadata injection.

## Requirements

To build and run this pipeline, your system requires the following:

* Standard C++17 compilation tools (MSVC 2019+, GCC 9+, or Clang 10+)
* CMake ($\\ge 3.14$)
* OpenGL 3.3 drivers & GLFW3
* `libtiff` (for uncompressed 24-bit RGB TIFF export)
* We recommend a dedicated graphics card to render high-definition images, especially with distortion or blur.

## Installation and Build Steps

### Windows (Visual Studio)
1. **Clone the repository**:
```bash
git clone https://github.com/Arky-dev/synthetic-scene-PhaseOne.git
cd synthetic-scene-PhaseOne
```
2. **Generate Visual Studio Solution:**
```bash
cd scripts
visual-studio-generate.bat
```
3. Open the generated `build/project.slnx` file (generated by the script) in Visual Studio, and build the solution.

### Cross-Platform (Standard CMake)

```bash
mkdir build && cd build
cmake --build . --parallel
```

## Running the Application

The pipeline supports both interactive graphical use and automated headless data generation.

### Launch using CLI

* **Default Capture Parameters**: Pre-configured for a $13468 \times 9564$ sensor ($2.6193\,\mu\text{m}$ pixel pitch, $25\,\text{mm}$ sensor height) with an $80\,\text{mm}$ lens at a $0.125$ world scale:
  1. Set image width and height (in pixels)
  2. Set desired focal length (mm)
  3. Set desired sensor size (mm)
  4. Set world scale factor
* **Depth of field simulation toggle** : Toggle thin-lens optical blur ON/OFF.
* **Capture modes**:
  1. _Capture mode 1_ is Manual : you can walk around the scene and render your images manually by pressing ``P``
  2. _Capture mode 2_ is Reading from file : you can provide a CSV file with camera positions, angles and focal lengths 
  3. _Capture mode 3_ is Random camera positions : The camera will be placed and rolled in positions uniformly according to parameters set in ``src/camera/camera.hpp``
 
### Modifying Parameters in Code
To apply custom lens distortion profiles:
1. Update parameter values in `src/camera/distortion.cpp` inside `distortion_function_mm`.
2. Enable distortion in src/camera/distortion.hpp:
```C++
struct DistortionConfig {
    bool enabled = true; // Toggle synthetic distortion pass
};
```
3. Recompile the project.

## Injecting the synthetic data to the Calibration Suite
The images can be injected into the calibration suite by following the protocol detailed in the repeatability investigation report.
